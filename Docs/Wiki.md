# 棋子 Piece
## Classic

以下棋子是在标准国际象棋中出现的棋子，在 GooChess 中，他们被迁移到了三角形棋盘上。

### Pawn

一般的国际象棋类似地，只能向前走，斜着吃。

```goochess
[5]
Pawn(4,4,4)
M(3,5,3)
M(4,4,3)
M(3,4,4)
O!(5,5,3)
O!(3,5,5)
(5,1,5)->(3,5,3)gray
(4,4,4)->(1,5,5)gray
(4,4,4)->(5,5,1)gray
```

当走到其他两方 3/c/iii 行时，可以**升变**至任意 *H等*/*K等* 棋子。

## *de novo*

以下棋子是完全生造的。

### Diplomat

这个棋子具有**控制**的能力。与之相邻的非 Diplomat 棋子不能做**任何行动**，包括移动、跳跃、技能。

被控制住的棋子如果身边（邻接三格）自家 Diplomat 数量大于等于其他两方 Diplomat 数量，就能“脱困”，恢复行动能力。~~让他几个吵架去，我先溜了~~

Diplomat **不能吃子** ~~谁家外交官出去嘎嘎乱杀啊~~，移动方式和 Knight 一致。

```goochess
[7]
Diplomat(5,5,5)
J!(4,5,7)
J!(4,7,5)
J!(5,4,7)
J!(5,7,4)
J!(7,5,4)
J!(7,4,5)
J!(4,6,6)
J!(6,4,6)
J!(6,6,4)
E!(6,5,5)
E!(5,6,5)
E!(5,5,6)
```

### Bomb

具有技能**爆炸**，炸毁（吃子）邻接三格的棋子。爆炸会在吃子、被吃和主动触发时发生。显然，不能被吃的棋子不能被炸毁。

所以，连锁爆炸是会发生的。

```goochess
[2]
bomb(2,2,2)
E(1,2,2)
E(2,1,2)
E(2,2,1)
```

吃子时会先移动，后爆炸。移动方式与 King 一致。

```goochess
[5]
bomb(4,4,4)
M(3,4,4)
M(4,3,4)
M(4,4,3)
M(3,3,5)
M(3,5,3)
M(5,3,3)
```

### Factory

具有技能**制造**，消耗 2coins 在邻接三格内选择一格生成一个 product 。  
若格内有自己的棋子或敌方不能被吃的棋子，这个格子不能用于制造。  
若格内有地方能被吃的棋子，那么这个格子中的棋子会被 product **吃**掉。

Factory **不能吃子**，移动方式同 King。

```goochess
[5]
factory(4,4,4)
M!(3,4,4)
M!(4,3,4)
M!(4,4,3)
M!(3,3,5)
M!(3,5,3)
M!(5,3,3)
```

### Product
不能升变的 Pawn。
